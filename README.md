## 💡 Нет подходящей темы? Предложите свою!

Если среди доступных тем нет подходящей, вы можете **предложить собственную тему** на рассмотрение.

### Как предложить тему:

1. Перейдите во вкладку [**Issues**](../../issues)
2. Нажмите **New issue**
3. Выберите шаблон своего уровня — формы отличаются, потому что отличаются требования к ВКР:
   - **"Предложение темы — бакалавриат"** — инженерный проект: текущий процесс (AS-IS), аналоги, какую характеристику улучшает решение, метрики «до/после», функции MVP
   - **"Предложение темы — магистратура"** — научная работа: новизна, проверяемая гипотеза, план эксперимента с базовыми подходами, ключевые публикации
4. Заполните форму и отправьте на рассмотрение куратору

### Что происходит дальше:

✅ **Куратор рассмотрит** ваше предложение  
💬 **Возможны уточнения** — следите за комментариями в Issue  
📝 **После одобрения** тема будет добавлена в каталог и вы сможете её зарезервировать

> 💡 **Совет:** Перед предложением изучите [гайд по методологии](diploma-info/guides/110-methodology.md), чтобы сформулировать тему правильно.

> 📝 **Обратите внимание:** Список доступных тем в форме резервации автоматически обновляется — отображаются только свободные темы.

## 📋 Чек-лист для студента

**Выбор темы:**
- [ ] Прочитал инструкцию [«Как зарезервировать тему»](diploma-info/how-to-reserve.md)
- [ ] Изучил [каталог тем](diploma-info/topics/README.md)
- [ ] Получил код доступа у куратора
- [ ] Создал заявку на резервацию через [Issues](../../issues/new/choose)
- [ ] Дождался автоматического подтверждения

**Подготовка:**
- [ ] Открыл [требования своего уровня](diploma-info/requirements/README.md) (бакалавр / магистр / ВКРС) и держу их рядом при написании каждой главы
- [ ] Изучил [гайды](diploma-info/guides/README.md) по методологии
- [ ] Внёс в свой календарь сроки из [графика дипломного проекта](diploma-info/guides/diploma-timeline.md)
- [ ] Настроил локальную среду разработки

**В процессе работы:**
- [ ] Готовлю каждую главу по [графику](diploma-info/guides/diploma-timeline.md) в порядке [«презентация → доклад → текст»](diploma-info/guides/diploma-timeline.md#методика-работы-над-дипломом):
  1. оформляю главу в виде рабочей презентации ([шаблон](diploma-info/templates/presentation/diploma-working-presentation-template.pptx));
  2. докладываю её на онлайн-встрече и вношу правки по замечаниям;
  3. пишу текст главы, вычитываю его сам и сдаю руководителю на вычитку к сроку из графика
- [ ] Пока идёт вычитка одной главы, готовлю презентацию следующей
- [ ] Регулярно консультируюсь с научным руководителем
- [ ] Веду документацию проекта
- [ ] Пишу научную статью параллельно с разработкой (магистры; бакалавры — по желанию)
