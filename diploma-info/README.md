# Репозиторий дипломных проектов

Этот репозиторий предназначен для хранения информации о темах дипломных проектов, руководствах для студентов и преподавателей, а также шаблонов документов и материалов, подготовленных студентами.

## Структура

- `topics/` — детальные описания доступных тем, их статусы и ожидаемые результаты. Темы едины для бакалавров и магистров; уровень определяется группой при резервации.
- `requirements/` — формальные требования к отчётности по уровням: структура, объёмы, обязательные артефакты, сроки, оформление ([`requirements/README.md`](./requirements/README.md) — сравнение бакалавр/магистр; там же раздел о ВКР в формате стартап-проекта (ВКРС), в том числе командного).
- `templates/` — шаблоны документов (заявки, планы, отчёты и др.).
- `guides/` — инструкции и рекомендации по работе с репозиторием и организацией дипломных проектов — *как* делать (оглавление и аннотации: [`guides/README.md`](./guides/README.md)). При расхождении цифр с `requirements/` правы требования.

## Как работать с репозиторием

1. Ознакомьтесь с описаниями тем в `topics/` и выберите интересующую.
2. Следуйте руководству по резервации темы из `guides/`.
3. Откройте требования своего уровня в `requirements/` (бакалавр / магистр / ВКРС) и держите их рядом при написании каждой главы.
4. Используйте шаблоны из `templates/` и актуализируйте руководства при необходимости.
