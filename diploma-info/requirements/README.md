# Требования к отчётности по ВКР

Этот раздел — **формальный слой**: что и в каком виде нужно сдать. Он отвечает на вопросы «какая структура текста», «сколько страниц», «какие обязательные таблицы и диаграммы», «какие сроки и процедуры», «как оформлять». Он **не** описывает, как выполнять проект — для этого есть [гайды](../guides/README.md), а сама постановка задачи — в [темах](../topics/README.md).

## Бакалавр vs магистр — сравнение ключевых параметров

| Параметр | Бакалавр (ИП, 2026/27) | Магистр |
| --- | --- | --- |
| Характер работы | Инженерный проект: полный ЖЦ разработки ПО | Научная / научно-практическая работа; научная новизна обязательна |
| Объём без приложений | 40–60 стр. (регламент ИП; решение руководителя, см. bachelor-2026-27 разд. 9) | 80–100 стр. (минимум 80 — требование руководителя) |
| Приложения | ≤ 1/3 объёма, ≤ 20 шт. | ≤ 1/3 объёма |
| Структура | Жёсткая: 3 главы × 3 параграфа (анализ → проектирование → реализация) | Введение, отдельный литературный обзор, основная часть (теория + эксперимент), заключение |
| Аннотация | ≤ 150 слов, 5–7 ключевых слов | ≤ 200 слов, 5–15 ключевых слов, статистика работы |
| Введение | Актуальность, объект/предмет, цель (через улучшение характеристики), 5 типовых задач, практическая значимость, структура | Актуальность, цель/задачи, объект/предмет; научная новизна и практическая значимость — обязательны по результатам |
| Гипотезы, новизна | Не требуются | Требуются |
| Обязательные артефакты | AS-IS и TO-BE диаграммы, таблица аналогов, таблица требований, схема архитектуры, ER-модель, макеты, таблица тестов, метрики «до/после» | Модели/методы/алгоритмы, экспериментальные результаты с обсуждением и вкладом автора |
| Источники | ≥ 20, ≥ 50 % не старше 5 лет | Число не регламентировано; требование руководителя — ≥ 30, обязательно иностранные |
| Публикации | Не требуются | Статья по материалам работы обязательна (п. 7.2) |
| Консультации | ≥ 1 раз в неделю, журнал посещаемости | По графику руководителя |
| Предзащита | Обязательна, онлайн, 11-я неделя весеннего семестра | Не регламентирована Положением; на кафедре — по решению руководителя |
| Антиплагиат | «Руконтекст», ≥ 55 %, 2 попытки | По СМКО 7.5.1/03.П.57, порог в Положении не задан |
| Рецензия | Не требуется | Обязательна, рецензент не с выпускающей кафедры |
| Сроки сдачи | 3 файла в СДО по графику; текст руководителю за 12 раб. дней, отзыв за 5 раб. дней, секретарю ГЭК за 2 дня; проверка комплектности за 3 и 2 дня | Текст руководителю за 12 раб. дней, отзыв за 5 раб. дней, секретарю ГЭК за 2 дня |
| Доклад | ≤ 5 минут, 12–16 слайдов | Вся защита ≤ 30 минут; в докладе обязателен пункт «значение для собственной карьеры» |
| Оформление | ГОСТ 7.32-2017, TNR 14, 1.5, поля 30/15/20/20, docx-шаблон кафедры | По методическим указаниям кафедры (ГОСТ 7.32-2017) |

## Как этим пользоваться

1. После резервации темы откройте документ своего уровня и держите его рядом при написании каждой главы.
2. Гайды в `guides/` объясняют, *как* получить нужные артефакты (сравнительный анализ, диаграммы, метрики). Если гайд и требования расходятся в цифрах — правы требования.
3. Календарный график и шаблоны документов публикует кафедра в СДО — они первичны относительно дат в этом репозитории.
