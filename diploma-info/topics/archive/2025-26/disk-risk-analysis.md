# Разработка программного обеспечения для анализа рисков и устойчивости дисковой подсистемы

**Статус:** Зарезервирована

## Краткое описание

Программное обеспечение для анализа рисков и оценки устойчивости дисковой подсистемы. Система предназначена для автоматизированного сбора метрик состояния накопителей (SMART-показатели, температура, скорость ввода-вывода, частота ошибок) и анализа/прогнозирования вероятности возникновения сбоев. Анализ данных позволит оценивать текущее состояние дисковой инфраструктуры, выявлять потенциально проблемные устройства и повышать общую надежность системы хранения данных.

В рамках темы диплома предполагается разрабатывать систему в рамках одного хоста: устанавливаемую на хост, на котором требуется анализировать и прогнозировать риски поломки дисковой подсистемы.

## Ожидаемый результат

- Программная система для мониторинга, анализа и прогнозирования рисков отказа дисковой подсистемы (один хост).
- Набор компонентов (агент/сборщик метрик, хранилище временных рядов, модуль анализа, визуализация, оповещения), разворачиваемых на целевом хосте.

## Возможные функции/компоненты

- Сбор метрик состояния дисковых устройств (SMART, температура, нагрузка, ошибки I/O).
- Хранилище и обработка исторических данных (InfluxDB/TSDB).
- Модуль анализа и прогнозирования вероятности сбоев (на основе метрик строится текущая характеристика работоспособности и прогноз).
- Веб-интерфейс для мониторинга и визуализации показателей (Prometheus + Grafana).
- Система оповещений о критических состояниях и рисках отказа (Alertmanager).

## Технологические ожидания

- Сбор метрик дисковой подсистемы: предпочтительно Go (при необходимости — более низкоуровневые инструменты/утилиты).
- Модуль анализа: Python (тип анализа TBD: real-time или на основе накопленных данных).
- Хранилище временных рядов: Prometheus и/или InfluxDB/TSDB.
- Визуализация: Grafana.
- Оповещения: Prometheus Alertmanager.

## Метрики успеха

- Снижение количества внезапных отказов накопителей.
- Среднее время раннего обнаружения потенциальных отказов.
- Снижение числа критических инцидентов.

## Основные use cases

- Системный администратор просматривает состояние дисковой подсистемы через веб-интерфейс, анализирует ключевые метрики и выявляет отклонения.
- Система автоматически собирает и обрабатывает данные, формируя прогноз вероятности отказа накопителей.
- При обнаружении рисков или аномалий система уведомляет администратора для принятия профилактических мер.

## Научная новизна и актуальность

Анализ показал, что в настоящий момент нет универсального решения, которое бы одинаково хорошо покрывало мониторинг SATA, NVMe и аппаратных RAID, и одновременно обладало бы развитым механизмом прогнозирования отказов. Существующие инструменты либо фокусируются на одной области (например, только SMART-атрибуты дисков), либо привязаны к конкретному оборудованию, либо предоставляют лишь базовые предупреждения без глубокого анализа.

Разработка системы, способной собирать метрики с различных подсистем, анализировать их динамику и заблаговременно предупреждать о рисках сбоя, является актуальной задачей. Это особенно важно для обеспечения высокой отказоустойчивости критической инфраструктуры, где даже кратковременный сбой может привести к значительным последствиям.

## Методы, модели и данные

- Методы: пока не известно.

### Метрики

Метрики для SATA/SAS накопителей — SMART-атрибуты. Пример:

- Reallocated_Sector_Count — число переназначенных секторов (признак деградации поверхности).
- Current_Pending_Sector_Count — количество секторов, ожидающих переназначения.

Более 15 метрик, которые можно собирать и анализировать.

Метрики для NVMe SSD: SMART / Health Information Log Page.

- Около 20 метрик, которые можно собрать.

Метрики для RAID-подсистем (аппаратные контроллеры) через специализированные утилиты. Примеры:

- Array_State — состояние массива (Optimal / Degraded / Rebuilding / Failed).
- Rebuild_Progress — процент восстановления после отказа.

Около 15 метрик.
